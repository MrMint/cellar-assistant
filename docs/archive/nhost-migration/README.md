# The Nhost/Hasura migration, archived

The backend moved off Nhost/Hasura onto Dapr actors in October 2026. These four
documents are the record of how it was planned and decided. They are frozen:
nothing they describe as Nhost, Hasura or the cutover exists in this repository
any more, and the Nhost Cloud project has been deleted. The pre-migration tree
is commit `82450ad1` in git history.

Code comments still cite some decisions here by number (for example "E4
decision 1"), because the reasoning is still why the code is shaped that way.
